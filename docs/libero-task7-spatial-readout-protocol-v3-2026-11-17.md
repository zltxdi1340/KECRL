## 唯一假设和两臂

检验在同一冻结ResNet18的`[N,512,4,4]`特征、同一下游控制头和500更新下，显式空间坐标读出模块是否更容易支持task7交接后的剩余搬运/放置。结果不单独归因于Softmax；模块差异还包含通道投影、坐标瓶颈、非线性深度和输出激活。

- `flat_zero_xyz`：共享`Flatten(8192) → Linear(8192,128) → ReLU`，保持原模块。
- `spatial_coordinates_zero_xyz`：共享`Conv1×1(512→256,bias=False) → SpatialSoftmax(4×4,τ=1.0) → 512坐标 → Linear(512,1408) → ReLU → Linear(1408,128)`。按用户列出的结构，最后是Linear，**不附加末尾ReLU**。

每相机输出128维，两相机共享同一个骨干与读出模块，参数只计一次。保持128×128图像、ImageNet通道处理、冻结卷积和BN、fusion256、原frame MLP/动作头。融合接口268=`128×2+joint7+gripper2+zero3`；两臂XYZ在网络内部生成恒零，不接受真实EEF输入，不读`ee_pos/ee_states`或`robot0_eef_pos/site_xpos`。不改变项目默认Policy或注册新Module。

空间网格的x随列向右增加、y随行向下增加，四个坐标为−1、−1/3、+1/3、+1，输出按每通道`(x,y)`交错排列。它是特征网格坐标，不是已标定像素/世界位置，也不预先命名为碗中心或盘中心。4×4不能直接换算为固定厘米误差；连续期望不能保证恢复丢失细节或达到3cm精度。

## 固定温度与熵诊断

温度τ=1.0是不可训练buffer，改变即技术拒绝；不做温度、通道数、宽度或初始化扫描。每热图对16个位置作空间softmax，坐标为位置期望。熵使用自然对数，`H=−Σp log p`、理论范围[0,ln16]；归一化H/ln16。数值范围/标量核对容差1e−6仅用于诊断，不放宽任何成败门。使用数值稳定log-softmax和entr(0)=0处理饱和。

候选训练每步记录两视图各自H之和/均值、每视图有效热图数、总体均值/归一化均值、有效帧数及τ。有效热图数=`valid_rows×256`，总体按有效帧×视图×通道等权平均，排除填充帧。控制臂为null/不适用，不伪造0熵。

统计必须**紧随该步缓存训练前向，并在parity前向/optimizer之前取得副本**，防止parity覆盖最近快照。候选每seed500条，共1500条；不为日志追加前向。闭环如记诊断，同样取已发生的候选预测（含丢弃预热），不重新运行网络。快照detach/clone、不保存梯度图；同一模型最多保留`3×80×256=61440`熵标量，不保存全量概率热图。未完成/失败的前向不能提供旧诊断。

均匀分布H=ln16、单点分布H≈0，两者都是合法诊断值。均值不能证明所有通道都聚焦；低熵也不能证明点对应目标或定位正确。**不以熵作成功门、早停、调温、选checkpoint或新loss**。独立审计核对记录的分母、标量关系和范围；不把标量一致性冒充对全部潜在热图的重演认证。

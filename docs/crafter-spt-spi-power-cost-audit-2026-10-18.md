# Crafter SPT→SPI 候选功效与成本审查

日期：2026-10-18。状态：功效与成本规划已完成；随后按下文假设冻结正式配置并启动 E1/E2。模拟仍是规划证据，不是实验结果。

## 研究量与现有样本

候选唯一主比较为 E2 中每个独立 replica 的三折平均 `B−C` 归一化 AUC，独立统计单位是 seed，而不是 fold 或 evaluation episode。候选为 10 个 seed，区间使用 seed 成组的 95% percentile bootstrap。候选 E2、E1 和合计交互步上限分别为 6,846,720、2,282,240 和 9,128,960。

E1 v3 pilot 的目标预算为 4,096 步，只有两个 seed；按 `0/1024/4096` 曲线计算的 B−C AUC 差分别为 `+0.0313`、`−0.1719`，均值 `−0.0703`，样本标准差 `0.1436`。这个方差估计只有 1 个自由度，且任务范围、预算和折结构都不同于 E2，不能用于声称 E2 的功效或设定其真实方差。

## 功效敏感性

为说明 10 个 seed 能检出多大的差异，模拟每个 seed 的三折平均差 `D ~ Normal(Δ, σ)`，对每份模拟数据计算 95% percentile bootstrap 区间，并统计区间是否排除 0。使用固定随机种子 `20261019`、每种效应/标准差比 3,000 份模拟数据、每份 2,000 次 bootstrap 重采样；表中 Monte Carlo 标准误约为 0.001–0.009。候选分析器正式设置为每次 10,000 次重采样。该正态分布只是敏感性假设，不是从两个 pilot seed 估计出的 E2 分布。

| `Δ/σ` | 10 seed 下区间排除 0 的比例 |
| ---: | ---: |
| 0.25 | 0.190 |
| 0.33 | 0.244 |
| 0.50 | 0.419 |
| 0.67 | 0.606 |
| 0.75 | 0.693 |
| 1.00 | 0.887 |
| 1.50 | 0.996 |

例如，若最小有意义提升为 `Δ=0.10`、seed 间标准差 `σ=0.15`，10 seed 的模拟检出比例约为 0.61；在同一假设下，15/18/20 seed 分别约为 0.744/0.817/0.848。若 `σ=0.20`，`Δ=0.10` 对应 10 seed 约 0.42，30 seed 约 0.79。若 `Δ=0.05, σ=0.15`，10 seed 约 0.24；正态近似的 80% 功效样本量约 71。若 `Δ=0.15, σ=0.15`，10 seed 约 0.89。

因此，10 seed 主要支持检测较大的标准化效应；它不支持“对小到中等 SPT 收益已有充分功效”的表述。结果依赖 `Δ`、真实 seed 方差、三折相关性和正态近似。模拟的区间排除比例是规划指标，不是预先批准的显著性检验，也不构成正式统计结论。

## 运行成本

E1 v3 两次独立运行用时分别为 115.55 秒和 115.11 秒。单次运行账本含 32,768 source 步、24,576 target-support 步和 20,894 evaluation 步，共 78,238 个实际交互步；按评估 episode 最长 32 步计算的上限为 80,384 步。由此得到约 677–680 个实际交互步/秒。

按同一吞吐率线性外推，E2 的 6,846,720 步约需 2.8 小时；E1 的 2,282,240 步约需 0.9 小时；合计约 3.7–3.8 小时单张 RTX 4090 串行运行。该估算基于短 E1 pilot，未验证正式规模下的运行抖动，也不包含失败重跑和机器竞争；不假设两张 GPU 并行带来提速。此前 E2 smoke 只有一个 seed 和极小预算，不能用于更可靠的满量运行时估计。

## 已冻结的规划选择

根据预先推荐并经用户“启动正式训练”指令确认的规划点，正式协议采用最小有意义 `B−C` AUC 提升 `0.10`、假设 seed 级标准差 `0.20`、30 个独立 seed（101--130）。对应的 bootstrap 敏感性模拟检出比例约 `0.79`，与 0.80 目标接近但不保证达到；该标准差仍是显式假设，不是 pilot 估计。完整 E1+E2 交互上限为 27,386,880 步，单卡估算 11.2 小时。正式 v1 配置将保留这个假设及限制，结果必须按 seed 汇总并在每个 seed 内等权平均三个 E2 fold。

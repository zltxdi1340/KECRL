# LIBERO受限视觉微调：已有配对轨迹的三假设读出协议（2026-11-14）

本轮按用户指令先分析[已完成的受限微调对照](libero-restricted-vision-finetune-results-2026-11-14.md)，不是重训、重放或新的闭环试验。输入限定本轮`training.json`、`training-audit.json`、`evaluation.json`、`completion.json`和其列出的240条公开episode JSON。既有结果与一条示例轨迹已被查看；以下指标在完整逐轨迹投影前固定，属于**结果已知后的探索性机制分析**，不冒充盲测、事前因果检验或正式准入门。

## 三种假设能与不能回答什么

| 假设 | 本轮可检查的线索 | 本轮缺少的辨别信息 |
| --- | --- | --- |
| 视觉与控制器联合更新不合适 | 同一reset观测的首动作差；共同初始化/批次；loss、裁剪变化及成功丢失/新增 | 没有更低骨干学习率干预或拆分视觉/控制器作用的反事实，不能归因于视觉层、学习率或“遗忘” |
| 示教拟合与自由运行有差距 | 每组末50个同身份训练批loss与闭环成功数；固定前缀两臂动作/公开状态分岔 | 没有保存RGB/隐藏特征的示教分布，也没有自由运行状态的专家正确动作，不能测分布距离或纠错误差 |
| 动作时序建模不足 | 动作连续差分、二阶差分、饱和及夹爪命令切换，任务/seed/配对outcome分层 | 没有时序模型对照，且动作抖动不是错误标签；不能从较大差分直接推出需要GRU/动作chunk或物理不稳定 |

首动作来自两臂相同的reset公开观测摘要、相同joint/gripper初值，因此首动作差说明已学映射不同。后续同一时刻两臂输入随执行而不同，动作差混合了映射差与所处状态差，不能当成同输入的纯Policy差或专家动作误差。

## 覆盖与计算定义

保留task4/7 × seeds20261106/07/08 × 初态0..19全部120对、240条episode。左臂始终为`frozen_resnet18`，右臂为`layer4_conv_finetune`，差值统一为微调减冻结。保留四格：两臂成功、仅冻结成功、仅微调成功、两臂失败；含空分组和仅一对的分组，不只分析失败或有利seed。

固定共同前缀H={1,5,20,50,100}，主要描述前缀H=50。只有两臂都执行至少H步时才计算该窗口；否则指标缺失并计截尾，不补齐、不时间伸缩、不把成功后的停止当零动作。先逐episode/配对求指标，再等权汇总均值、中位数、最小/最大和有效/缺失分母。全长指标另存，仅作自身描述，不能把不同长度全程均值直接当同阶段比较。

- 首动作：七维命令L2差，并分开平移0:3、旋转3:6、夹爪6。命令均为归一化控制量，各分量物理含义不同，合并L2不作真实空间距离解释。
- 前缀动作：平移/旋转命令范数、夹爪绝对值；相邻命令差及二阶差的平均范数。H<2/3时相应差分记null；这些是命令差分，不是实测机械臂加速度或jerk。
- 饱和：逐分量`abs(action)>=0.95`的比例，平移/旋转/夹爪分别统计；边界等号计入。
- 夹爪命令：`>0.1`为正向close、`<-0.1`为负向open，其余中性；计算首次正向命令及之后首次负向命令。切换次数在去掉中性命令后计相邻符号改变，记录有效命令数；不足两条时切换率null。它们是命令事件，不能当作抓住、运输或放稳的真实阶段。
- 公开状态：每步joint/gripper向量位移范数和路径长度；同一时刻两臂动作前/后状态间距离，及前缀平均距离。joint距离不是末端/物体到目标的距离，也不是接触、动力学或任务进度指标。
- 每个前缀分别保存两臂值、差值及动作/状态间距。仅对方向计数将`abs(delta)<=1e-12`记为数值零，原差值原样保留；这是解释性计数的浮点约定，不修改原成功门。
- 训练：12模型分别按50更新分10段；6个task×seed配对比较末50批loss、裁剪次数和成功数差。精确检查500批身份/有效行配对，不把训练minibatch loss称为独立query误差。

汇总覆盖全部、每task、每seed、task×seed、每outcome、task×outcome、task×seed×outcome，共48个分组及各5个固定前缀。空事件缺失不当作零，事件发生顺序沿用已有censor-aware helper；一臂先结束时保留“不足以比较”状态。

## 访问、预算与核对

只使用已有新输出，研究checkpoint、公共预训练权重、HDF5、初态容器和私有simulator state均不打开或SHA；不导入Torch、HDF5、MuJoCo、robosuite或LIBERO runtime。历史冻结代码不改写，复用已有统计与事件截尾helper。

主分析和独立核对各读取4份已pin顶层JSON及240份已pin公开episode一次，各244次source JSON解析、≤256MiB source字节；两角色合488次。模型前向、backward、optimizer、环境step、新episode和研究原始数据/模型读取上限均为0。输出120配对行、600前缀行、12训练模型行、120训练分段行和6训练配对行，写新的持久盘results目录，拒绝覆盖。输出自身读取、表格核对和后续绘图不计为source重读，均不得打开新的研究输入。

新执行绑定在完整逐轨迹投影前pin配置、源码、旧573项依赖、测试证据及四个source JSON。主分析用NumPy公式；独立核对用Python标量`math`/`statistics`重算全部配对、前缀、分组、训练指标和CSV单元格，数值核对采用abs1e−12/rel1e−11，身份/计数/分母精确。此容差不用于实验成功判门。

不生成新的成功率门、不做因果/显著性推断、不挑选checkpoint或回改既有试验结论。若仅发现映射分岔、轨迹差或不一致的连续性指标，三项根因仍记未识别；后续优先获取能区分假设的观测/干预，另行固定预算与作用域。500更新、5步稳定化、原loss及正式数据封存保持，LIBERO继续作为主环境。

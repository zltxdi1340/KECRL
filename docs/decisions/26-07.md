# 2026-07-11

## Decision 001

### 主题

确定整个项目的核心研究方向。

### 最终决定

项目核心不再是：LLM + RL。

而是：Knowledge Evolution（知识演化）+ Skill Evolution（技能演化）共同驱动持续学习。

LLM 仅作为未来可选知识先验。


## Decision 002


### 主题

Module 保存什么？

### 最终决定

Module 为技能库中的基本单位。

每个 Module 保存：

- Skill Program Instance（SPI）
- Policy
- Experience
- Metadata

Module Library 持续扩展。


## Decision 003


### 主题

SPT 如何演化？

### 最终决定

每个 Skill Family 维护一个 Global Skill Program Template（SPT）。

多个 Skill Program Instance（SPI）共同反向更新对应 SPT。

SPT 持续提高未来技能学习效率。

## 今日完成内容

### 1. 完成 Scientific Question

明确项目研究对象为：Knowledge Evolution（知识演化）和 Skill Evolution（技能演化）共同驱动持续强化学习。

### 2. 重构整体系统框架

最终确定系统由两个长期记忆组成：Knowledge Bank（知识库）和 Module Library（技能库）

Knowledge 决定学习什么。

Skill 决定如何学习。

### 3. 定义 Knowledge

Knowledge 保存 Capability 之间的依赖关系，不保存具体 Policy。

Knowledge 用于指导：
- 技能发现
- 技能迁移
- 技能组合


### 4. 定义 Skill Evolution

提出技能结构：Skill Program Template（技能程序模板，SPT） 和 Skill Program Instance（技能程序实例，SPI）

SPI 共同推动 Global SPT 持续演化。

### 5. 定义 Module

Module 为技能库保存的基本单位。每个 Module 保存：

- SPI
- Policy
- Experience
- Metadata

## 今日总结

持续学习真正需要演化的不是 Policy。

而是：Knowledge（知识）、Skill Program Template（技能程序模板）

Policy 是执行器，Knowledge 与 SPT 才是长期积累对象。

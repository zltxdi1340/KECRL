# LIBERO固定500模型的合爪确认门配对对照（2026-11-14）

承接用户“按三步推进”及[前两步画面证据](libero-gripper-approach-visual-results-2026-11-14.md)，仅在task7已用source开发初态0..19执行新的有界配对闭环。明确的早合爪短脉冲来自冻结臂，故两类模型均纳入，不能先假定这是微调独有问题。本试验冻结一种确认门，不扫阈值或步数，不训练。

## 配对与唯一干预

固定原task7三个seed、冻结/受限微调两类共6个原Policy500完整checkpoint；每模型对同20个初态分别运行unchanged和confirm5，共120对/240条fresh episode。两条件每模型各新建环境，按0..19顺序reset，原seed20261022、5个稳定化零动作、300动作上限、原128×128双视角与运行栈保持。旧240条评价授权不转用，当前三步指令在本阶段另建新授权和执行绑定。

unchanged：原7维命令直接执行，要求120条完整轨迹逐步复现原记录的reset摘要、动作、joint/gripper、终止步及成功。任何偏差立即技术停止，不把漂移后的结果当有效对照。

confirm5：每episode独立计数连续正的第7维原输出，前5个正请求的第7维改为0（原生gripper保持当前目标），第6步仍为正才原样放行；正计数封顶6。原输出≤0立即原样通过并清零计数，开爪不延迟。符号阈值严格为0，与旧0.1分析锚点区分。保存每步raw/applied、计数与masked标志，其他6个通道保持本步模型raw输出逐位不变。

两条件使用相同固定模型；候选改变环境反馈后，后续raw输出及其他6维动作可以随新观察变化，不能宣称两条整轨迹的6维命令仍相同。本规则同时延后持续合爪并过滤短正脉冲，若改善不能区分二者贡献，也不能证明合爪过早是全部失败原因。

## 访问与预算

每个完整checkpoint只解码一次、模型共享于两条件，前后及两条件结束分别核对完整权重SHA，共18次。按原类图构造空结构，strict加载全部保存参数/缓冲；不读取ImageNet初始化权重，不下载，不创建优化器。模型全部eval/无梯度；测试须检验重建结构加载人造完整state后的输出精确一致。

原训练元数据的actual_optimizer_steps是逐参数Adam步数列表，长度必须等于parameter_mask.names且每项均为500；不能当作单个整数，也不能把列表求和误算成Policy更新数。

初态选择性reader单次解码task7的0..19共20行，立即保存真实收据，其他行不数值解码。原120份task7 episode JSON只用于原unchanged复现；主/审计各读一遍。不读示教HDF5、meta_query、validation、H、heldout、qualification、reserved、final或物体/接触私有状态。

## 事前决策与停止

主指标为两类×三seed等权平均成功率，因各cell均20条，等于每条件120条总体成功率。继续此候选须平均提升≥10个百分点（净增至少12/120），且每类模型均值不退化、每seed均值不退化；原成功保留/新成功/损失配对全部描述，不隐藏退化案例。拒绝后不扫描其他确认步数救当前版本。

任何来源、权限、原unchanged复现、权重、原生动作、预算或终止错误都技术停止、不重试。技术审计通过与科学继续门分别报告；source开发结果不是正式迁移或完整KECRL验证。Policy500、稳定化5步、现loss和正式数据封存保持，不更新SPT/Knowledge或注册Module，LIBERO继续为主环境。

## 冻结范围与分类

[配置](../configs/libero-source-expert-component3-error-types-readonly_v1.json)在真实NumPy缓存加载前绑定代码、测试和上一轮配置/结果/独立审计SHA，沿用task0/1/3/4/7、seed20261106/07/08、A_original/B_fomaml全部30个500端点。读取已有5份label NPZ和30份prediction NPY，source meta_support demos0..29、t≥1；不访问checkpoint、HDF5、RGB、source query、环境、初态或private状态。第3分量是action数组index2，不直接称世界z位移；末20为示教时间分层，不是接触/释放标签。

主分类按保存的float32数值转float64后比较，六类互斥且覆盖全部帧，不加epsilon：

| 类别 | 定义 |
|---|---|
| wrong_sign | 预测与非零目标严格反号，p×y<0 |
| prediction_zero | 非零目标而预测恰好为0 |
| same_sign_under | p×y>0且abs(p)<abs(y) |
| same_sign_over | p×y>0且abs(p)>abs(y) |
| exact_match | p=y，含两者都为0 |
| zero_target_nonzero | 目标恰好为0而预测非零 |

保留目标负、零、正及全部四方向；固定all、每demo末20、补集三时间层。全部帧为主口径，另用对称的`abs(y)≥0.025`作material目标参照；它沿用既有0.025尺度但不是阈值搜索，也不改变原始错号标签。material目标上的错号再标记`abs(p)<0.025`与`≥0.025`，检查临界输出与明显反向输出。目标零与预测零不能混成同一种错号。

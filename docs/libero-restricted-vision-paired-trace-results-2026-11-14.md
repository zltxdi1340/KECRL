# LIBERO受限微调：全部配对轨迹的三假设筛查（2026-11-14）

**已分析全部120对/240条既有轨迹及600个固定前缀，独立核对通过。最明确的新线索是：微调从首动作就改变了映射，且夹爪命令时机发生任务相关变化；“微调后动作更抖”不受前50步数据支持。联合优化、示教分布差距与时序能力三项根因仍未被因果识别。** 本轮无模型前向、训练或新episode，LIBERO继续作为主环境。

科学口径见[探索分析协议](libero-restricted-vision-paired-trace-protocol-2026-11-14.md)。[原闭环](libero-restricted-vision-finetune-results-2026-11-14.md)冻结16/120、微调12/120及三个继续门未通过的结论保留。本轮已知结果和一条示例后才固定指标，属于探索性分析，不是新的盲测、显著性或因果检验。

## 三项假设的结论

| 待检验原因 | 已观察到什么 | 当前能作出的判断 |
| --- | --- | --- |
| 视觉与控制器联合更新不合适 | 所有120对的reset观测摘要及公开初值相同，但首动作均不同；成功丢失和新增均出现，训练裁剪次数从306降至108 | 已学映射/优化轨迹确有变化，不能区分视觉层、head、学习率或两者协同效应；未证明学习率过大、遗忘或过拟合 |
| 示教拟合与自由运行存在差距 | 6组中5组末50个同身份训练批loss下降，其中3组成功数仍下降；两臂后续公开状态逐渐分离 | 拟合指标不能代替闭环成功；没有示教分布或策略状态专家标签，尚未测到“出分布”或纠错误差 |
| 动作时序建模不足 | 前50步多数配对的动作差分更小，但task7多数微调臂更早发close；task4前50步close反而减少 | 不支持“失败主要因为微调更抖”的简单解释；存在命令时序线索，不能据此确认时序模型不足或直接采纳平滑/GRU/动作chunk |

## 首动作分岔不等于失效原因

120对首动作七维归一化命令L2差中位数0.179786，范围0.047482..0.825656；分量块中位数分别为平移0.165652、旋转0.038069、夹爪绝对差0.040041。它不是物理空间距离。首动作之前的joint/gripper差为0，reset摘要严格相同，因此此时差异确由已学映射产生；后续两臂观察不同，不能再把同一时刻的动作差当成同输入Policy误差。

按配对结局，首动作差中位数为：仅冻结成功0.126123（n=15）、仅微调成功0.182921（n=11）、共同失败0.179892（n=93）；唯一共同成功为0.323432（n=1）。成功丢失组没有最大的首动作差，n=1也不足以估计稳定规律。

例如task7/seed20261106首动作差最大但成功增加，seed20261108差较小却成功减少，不能建立“改动越大越差”的统一解释。loss是实际训练minibatch读数，非独立query误差；没有用它筛选checkpoint或改变原门。

## 轨迹分离与动作连续性

全部120对在H={1,5,20,50,100}均有完整共同前缀，无需补齐。两臂动作后joint状态间L2距离中位数从第1步0.003766，到第20步0.189970、第50步0.557777、第100步1.070991。该量仅描述joint坐标中的两条路径间距，不是末端/物体目标误差，更不是到示教分布的距离；不同路径也可能都成功。

下表先逐episode计算前50步平均相邻命令差，再对120对等权汇总。数值越小只表示该命令差分更小，不自动代表物理控制更好。

| 命令块 | 冻结均值 | 微调均值 | 微调更小的配对 |
| --- | ---: | ---: | ---: |
| 平移0:3 | 0.061220 | 0.053916 | 82/120 |
| 旋转3:6 | 0.012495 | 0.007700 | 116/120 |
| 夹爪6 | 0.046063 | 0.028302 | 103/120 |

二阶命令差也分别在111/120、118/120、100/120对中更小。在15个丢失成功的配对里，相邻平移/旋转/夹爪差分分别在13/15、15/15、13/15对更小，二阶差亦同方向。于是本轮不应把“更强平滑”当作已获支持的修复。另一方面，命令更平滑不能排除阶段切换、记忆或纠错能力不足。

## 夹爪时机有任务差异

命令阈值事前固定为`>0.1` close、`<-0.1` open，中间为中性；这些不是实际抓取/接触标签。

- **task7：** 全程60对两臂都观测到首次close，微调54对更早、5对更晚、1对相同。前50步已发close的数量从冻结43/60变为微调54/60；两臂都在前50步close的42对中，39对微调更早、2对更晚、1对相同，时差中位数−7.5步。它可能关联行为变化，但缺少目标相对位置/视觉，不能判断是否“闭合过早”。
- **task4：** 前50步已发close从17/60变为2/60，方向与task7不同。按全程censor-aware比较，6对微调更早、21对更晚；14对仅冻结观测到close且其事件发生在微调观测终点以内，19对则反向。不能由此推出一个跨task统一的夹爪时机规则。

这里保留全部seed和四格，不只分析15个丢失样本。93个共同失败和唯一共同成功也保留；没有以命令事件推断真实抓取、搬运或放置阶段。

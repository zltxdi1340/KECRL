# 六组source内部闭环配对轨迹：只读分析定义（2026-11-03）

分析[已经完成并审计的360条轨迹](libero-source-internal-spt-spi-closed-loop-diagnostic-2026-11-03.md)，保持18个500-update端点、稳定化5步和全部封存角色。先固定以下定义，再计算新分层；配置见[只读分析v1](../configs/libero-source-internal-six-group-paired-trace-readonly-analysis_v1.json)。

1. 主比较覆盖task0/1×三seed全部六组，每组20对B-A和20对B-C，共240个配对记录。两者成功、仅左成功、仅右成功、共同失败四格都保留；同一B轨迹在两个比较中重复，不充当新的独立样本。
2. 次级seed对照覆盖每个task和每个臂的全部三个seed两两组合，共360对，仍只复用原360条轨迹，不增加场景或筛选有利seed。
3. 首动作报告七维向量及平移/旋转/夹爪分量、符号与跨Policy差。reset观测摘要和公开状态必须一致；这能区分“首动作之前已存在的Policy映射差”与后续闭环分叉，但没有专家目标动作，不能判断哪一个动作正确。
4. close为正夹爪命令，open为负，neutral为零；release仅指首次close之后的首次负命令，不等于物体释放。分别统计首次close、首段持续长度与右删失、最长close、close比例、符号切换、首次release及close→release间隔。没有close与close后未见open分开；事件缺失用null而非301或0。
5. 缺失事件属于观测截止：若另一臂事件发生在该臂记录结束之前，可给出有界先后关系；否则标为无法比较。均值/中位数同时报告总数、有效数和缺失数。全失败或空四格不得补造成功样本。
6. 同步时间点固定1/5/10/20/50/100/200/300。action[t]基于obs[t-1]，row[t]为动作后的状态；row0为五步稳定化后的reset。只在双方都到达该时刻时算配对差；晚期数据有存活者选择，不用成功终点向后填充。
7. 早期主窗口固定前20步；双方都有20步才计算完整20步比较。另列min(20,两条长度)的已观察共同前缀及其长度。记录action差、joint/gripper轨迹距离和路径；相对reset的位移不是专家状态误差，跨轨迹距离也不是控制质量。
8. 所有episode与pair标识、六组及四格分层、各臂成功/失败描述保留；不做事后显著性、物理抓取阶段、视觉根因或Knowledge机制结论。夹爪幅值与runtime符号命令的区别沿用已有映射核对。

只读主JSON、独立审计与冻结元数据，不加载Policy或checkpoint，不读HDF5/RGB/初态，不创建环境，不做训练或新前向。原始轨迹没有RGB像素、物体坐标或专家动作，故不能由本轮唯一归因到视觉、action head、数据覆盖或目标接近阶段。即使发现命令模式，也先报告反例和seed限制，再决定是否需要新诊断，不能自动触发训练修改。

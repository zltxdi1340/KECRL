## 同一参数与原四参照条件

四参照顺序固定为control（当前guarded T）、margin（原负裕度T）、zero（旧零裕度T）、bisector（旧角平分）。每头每套P/U历史分别从原缓存取得各参照M/P/T；原值不换成新测值、均值、较弱参照或两历史合并值。

- M为动作第3分量（索引2）的专家MSE。
- P为该分量相对原Policy逐帧平方误差的正超额均值/7。
- T=M/7+P，λ=1；其余6维动作固定为缓存原Policy动作。
- M_cap=min(M_control,M_margin,M_zero,M_bisector)，T_cap同理；保留全部并列活跃参照。
- 共同条件：**同一个θ同时满足M(θ)≤M_cap且T(θ)<T_cap**，并逐一输出四参照的原始比较。两条件不能由不同参数各自满足后拼接，不新增P上界。

M/T原始比较不加epsilon，T严格小于，M可等于。数值重演核对为绝对1e−10、相对0，M/P/T守恒同此容差；该容差不进入通过门。同参数结果即使差小于容差，原始布尔门不同仍如实保留。

辅助头θ为原固定当前表示的256权重+1偏置。在同一own20 fit标准化坐标中，以Float64计算：

```
z = float64(float32((float64(features[fit_rows])-saved_mean)/saved_scale))
raw3 = float64(p0_3) + (sum(z_j*theta_j) + theta_bias)
pred3 = clip(raw3,-1,1)
M = mean((pred3-expert3)^2)
P = mean(max((pred3-expert3)^2-(p0_3-expert3)^2,0))/7
T = M/7 + P
```

沿用原fit20均值/总体标准差、scale≤1e−6置1和Float32中间cast，缓存scaler须按原顺序重算并以原1e−10核对。只读own20 fit的t≥1全部帧（含neutral）；encoder已见全部30示教，不能称未见泛化。每折2782/2817/2777帧、20示教，head身份、角色、归一化坐标、n、更新数与历史都须核验。保存的其他6维原Policy动作不能由新头改动，不额外做动作Float32重舍入。

## 固定有限网格与独立复核

先评估四个参照端点一次，再按四参照顺序的6个无序对，在每对上取α=j/32，j=1..31。每头恰好4+6×31=190配方；端点原样复制，中间每坐标严格按`left + alpha*(right-left)`构造，Float64、禁止FMA/重排、参数修补、重缩放或溢出回退。非有限值技术停止。即使两个配方参数相同仍计两个槽位；不基于M/T去重、提前成功停止或细化网格。这只是6条边的有限采样，**不是整个凸包，也不保证边上的可行区间都会被命中**；clip目标也不能未经证明当作全局凸问题。

参数取原四参照的保存端点，不用上轮新联合T候选做第五顶点，不从当前端点继续训练。每个配方记录身份、来源历史、配方/α、257坐标摘要、M/P/T、原始/重演逐参照比较及门；全表留存，无best checkpoint或模型选择。

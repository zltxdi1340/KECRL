# KECRL 运行与实验参数清单

> 日期：2026-09-29；状态：实现前清单，内部评审。依据 [PROJECT_BIBLE](../PROJECT_BIBLE.md) 第 6、7、9 节；未列具体数值的项目不得被视为已冻结实验方案。运行/实验用途可以重叠，“未定”描述决策状态。

## 理论固定项

| 项目 | 固定规则 |
|---|---|
| Capability Schema | 审核后冻结为 `V_t = V_0`，在线不能创建新 Schema |
| 机制 | `M=(P_start,P_hold,Y)`；同机制父条件 AND，同目标多机制 OR |
| 证据统计 | 有效支持/反证进入 Beta-Binomial；UNKNOWN 不进入分母 |
| 确认/拒绝 | `n >= n_min` 且 `L >= tau_confirm`；或 `n >= n_min` 且 `U <= tau_reject` |
| 更新边界 | Knowledge 与 Skill 独立更新；Planner 不是长期知识库 |
| 主技能算法 | 上下文条件化 FOMAML，support/query 分离 |
| 调度顺序 | 有效反证质疑的 confirmed 优先，其次当前目标不确定项，再处理其他候选并照顾久候任务；不改变确认标准 |
| 资格与版本 | 独立资格评价、硬契约约束、候选独立比较、保留上一稳定版本；不规定完整生命周期 |

## 实验参数（阶段性提案，2026-10-03）

阶段性选择：第一阶段采用受控离散资源环境，Crafter 后续接入；任务族为机制识别与技能元学习；Baseline 保留 Module 复用并关闭两类 Evolution；Ablation 分别关闭 Knowledge Evolution、Skill Evolution；主指标为独立 query 学习效率；seeds 为 `0,1,2,3,4`。详细预算候选与操作定义见 [实验协议](experiment-protocol.md)。

| 参数 | 当前状态 |
|---|---|
| `n_min` | 候选 10 个同范围有效证据；先导验证后复核 |
| `tau_confirm`, `tau_reject` | 候选 `0.8`, `0.2`；先导验证后复核 |
| 后验置信水平/分位点方法 | 候选 0.95；计算方法待定 |
| 验证任务成本估计与预算换算 | 候选每 seed 200 个验证单元；单位定义和任务成本待定 |
| Module 资格样本数、成功率/契约阈值 | 候选 20 episodes、成功率 0.8、硬契约零违规；未知/无效的处理及资格置信规则待先导验证 |
| Module qualification 的范围分组与评价预算 | 未定 |
| SPT 接受的最小改善量 | 候选 query 学习步数改善 10%；配对不确定性判据待定 |
| 既有 SPI 非劣/退化容忍界 | 候选成功率最多下降 0.05 |
| SPT 回滚检测窗口与系统性退化标准 | 候选连续 2 个独立 validation batch；硬契约/安全违规立即拒绝/恢复 |
| Policy 后端、环境、基线、指标、任务划分 | 环境/任务族/baseline/ablation/主指标/seeds 已作阶段性选择；Policy 后端、具体任务实例和划分仍待实现后冻结 |

`Delta` 等成本实际意义阈值、资源配置和正式统计检验同样保持未定。Crafter 木镐数字仅为流程示例，不是参数或实验结果。

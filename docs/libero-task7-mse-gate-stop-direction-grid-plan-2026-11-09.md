## 数学定义与可回答边界

沿用 `A=MSE3/7`、`T=A+P`、`F=C6+T`，C6固定；P内的e0来自原Policy，接受上界M500来自各头自身辅助500，两者不混用。保存的向量为 `Gb=A的导数选值（可微时为∇A）`、`Gp=被选取的P次梯度`、`G=Gb+Gp`、`d=-G`。逐坐标核对G和d的恒等式、重算范数对齐缓存；零更新两点的全部四向量及所选标量须精确相同。

每个点输出：四向量范数、Gb·Gp及cosine、Gb·d/Gp·d/G·d、起止向量变化范数、clip/hinge拐点计数。范数为0时cosine为null，不加epsilon；cosine在1e-10舍入范围内裁到[-1,1]仅作数值范围处理，不改变方向或训练接受规则。

**不能默认 `G·d=-||G||²` 就是实际总目标单侧导数。** 总目标真实右导数sT直接使用上一轮按clip/hinge实际分支计算并保存的 `directional_derivative`。点积是被选取次梯度的投影，两者的gap需保留。

- 若clip_low_tie_n + clip_high_tie_n = 0，A在该点对该方向可微，专家MSE3的精确方向导数为 `sM=7 Gb·d`。即使存在hinge零点，这个MSE导数仍可用，精确惩罚单侧导数可由 `sP=sT-Gb·d` 得到。
- 无clip拐点时，`sT-G·d`应不低于−1e-10；若也没有hinge零点，则两者应在绝对1e-10内一致。存在hinge时必须保留修正gap，不用 `Gp·d`替代精确sP。
- 存在clip边界拐点时，现有向量不足以重建逐帧单侧MSE导数。sM/sP标为null，保留点积代理描述，不能据此判定MSE局部上升/下降；不得读取特征补算。

这不是重新算梯度或试新方向。所有方向/范数/点积均由保存向量派生；没有新前向、autograd或finite difference。

## 方向与网格的判据

固定余量 `S=M500-Mstop`，必须严格S≥0；不得用1e-10放宽这个已执行的约束。所有末轮必须对应缓存sT<0，实际α仍是2^-j、j0..11，最小1/2048；旧试步的两个判断和接受结果按原严格规则重建，绝不加容差重标。

用于新描述性推论的数值带固定为绝对1e-10：同时输出严格符号及近零标志，不用近零带改变S或任何试步通过/拒绝。推论分开列出：

| 保存记录的条件 | 允许的解释 |
| --- | --- |
| S>1e-10且sT<−1e-10 | 以保存数据构成的连续数学目标为参考，余量为正、总方向导数为负，存在足够小正步长同时满足MSE约束和Armijo的条件性推论；当前网格没有找到。没有评估其实际值。 |
| S=0、无clip拐点、sM>1e-10且sT<−1e-10 | 当前方向在约束边界附近增加MSE；沿同方向把α任意缩到足够小，并不能在该局部邻域满足约束。不排除更大步、别的方向或全局可行解。 |
| S=0、无clip拐点、sM<−1e-10且sT<−1e-10 | 两个目标局部都下降，具有局部小步可行的条件线索；不把它写成新试步成功。 |
| S近零但非零、sT近零、边界sM近零或clip拐点未解 | 保留未确定分类，不能用一阶记录排除曲率/舍入/分支影响。 |

正余量条件下的小步存在性来自连续性及负方向导数，不要求MSE方向也下降；它不保证有限精度能观察到可用改善、不确定一个实际安全步长，也不证明继续加预算或扩网格能改善泛化/控制。

若S>0且精确sM>0，只报告线性尺度 `alpha_linear=S/sM` 与1/2048的比值，明确它不是安全步长或上界证明。末轮每个已有试步报告：Mtrial−Mstop、Mtrial−M500、ΔP、ΔT、Armijo margin、MSE割线斜率；sM可用时再给αsM及其残差。验证 `ΔT=ΔM/7+ΔP` 和固定C6，不能把有限步长的高阶残差当局部导数。**不评估任何未试过的α，不读取特征，不添加方向搜索。**

每个头给起点/停止点变化及末轮12点的两个判断分布。六来源×seed单元再各列zero/short两层共12组，保留空组；等头描述、逐折值，不把折当独立seed、不做p值或未经允许的因果判断。7个full50头仅作为metadata分母；本项不声称对照它们的梯度。

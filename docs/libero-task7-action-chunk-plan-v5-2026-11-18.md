# task7 v5：H=4、k=1 联合动作预测科学方案（2026-11-18）

## 检验问题与范围

在冻结 ResNet18 `[512,4,4]` 特征与共享 3A 空间读出（512→256 通道，固定 τ=1，坐标 MLP 512→1408→128）之上，检验联合预测当前及未来三步动作的监督，是否改善同状态交接后的控制。每次只执行首动作，下一步重新读取当前公开观测并预测；不执行未来动作队列、不引入历史，也不主张已证明停滞、分布偏移或多步执行是原因。

两臂为 `h1_spatial_control` 与 `joint_h4_k1_spatial`。双相机、7 维关节、2 维夹爪不变，268 维融合接口末尾 XYZ 始终内部置零。不读取 EEF/物体私有真值，不增加传感器。此对照检验联合监督机制，未来标签使有效监督对的分布发生变化，不能称两臂有效目标完全相同。

## 参数与初始化

两臂非骨干登记参数均 **1,504,541**，含原共享 3A 的 1,499,144 与三个独立 `Linear(256,7)`（每头 1,799，合计 5,397）。含冻结骨干的总参数为 12,681,053。控制臂后三头冻结、跳过计算、不进 Adam，实际可训练 1,499,144；候选实际可训练 1,504,541。保留原 `action_head` 为 h=0。

每 seed 的全部初始 state_dict 相同；共享视觉读出、融合及控制层沿用 v3 初始化。未来头分别在局部 RNG 中采用 seed 加 9,700,001 / 9,701,001 / 9,702,001，不改变原初始化或批次 RNG。两臂各 seed 使用相同 500 个八窗口 minibatch。控制臂 H0 保持旧 contiguous 七维 masked MSE 路径，以避免无意义的归约变化。合成测试核对动作、loss、梯度与两次 Adam 更新逐位一致。

## 标签与双层掩码

只读 task7 meta_support demos0..29，沿用因果 t≥1 的 sequence=10、stride=10 缓存窗口。设窗口从示教 s 开始，长度 T≤10，示教动作长度 N，局部索引 t 从 0 开始，偏移 h∈{0,1,2,3}：

- 锚点掩码 `B[b,t] = valid_mask[b,t]`。
- 未来掩码 `F[b,t,h] = (t+h<T) AND (s+t+h<N) AND valid_mask[b,t+h]`。
- 臂掩码 A：控制 `[1,0,0,0]`，候选 `[1,1,1,1]`。
- 标签仅取同一已缓存窗口 `actions[b,t+h]`；窗口或示教末端外填零且不参与 loss。

联合七维 MSE 为：

`L = Σ[b,t,h,j] B·F·A·(prediction[b,t,h,j]−target[b,t,h,j])² / (7·Σ[b,t,h] B·F·A)`。

完整十步窗口 t=7/8/9 有效偏移分别为 `[0,1,2]` / `[0,1]` / `[0]`，共34个锚点—偏移对。示教先结束时还必须截断；不跨窗口补标签、不读取未来图像。输入的 valid_mask 必须与 s、N 一致且为前缀。既有审计元数据的432窗口、4,188当前有效动作对应候选 **14,168** 对，非4倍填满的16,752。两臂总loss不作同一量比较，另记 H0 及各偏移 MSE。

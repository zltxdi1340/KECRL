# LIBERO夹爪命令与接近目标：有界动作重放视频协议（2026-11-14）

本轮准备回答：**发出close命令前，夹爪在可见画面中是否已经对准目标黑碗？** 依据[已有配对轨迹分析](libero-restricted-vision-paired-trace-results-2026-11-14.md)，task7微调臂54/60对更早发close，但没有RGB可判断时机；动作更抖也未获支持。本协议只准备，尚未获得本版本重放授权或建立执行绑定，不运行新的真实环境。

## 方法与解释边界

原记录已有每步动作，因此采用**保存动作的当前栈重放**，逐条执行原命令，补录原Policy可见的两个RGB视角。它保留原checkpoint SHA来源，但不加载checkpoint、不构造Policy、不重新推理或训练；不是一次新的Policy闭环评价，不重新估计成功率，也不改变原240条结果。

重放仅在原reset RGB/公开状态摘要完全相同、每一步joint/gripper状态逐位相同、原生终止在窗口内一致时接纳；任一不符即停止，保留failure，不换例、放宽容差、修复状态或自动重试。每个保存动作必须原样进入一次受控native step。原adapter仍使用300动作上限/native horizon305，本诊断在100个动作后主动结束，不能把该停止标成任务失败。

**补录画面是当前环境的重建，不是已丢失原视频的精确恢复。** 原RGB只保留reset摘要，后续物体/接触状态没有独立原记录；公开前缀一致不能证明全部私有物理状态一致。视频用于观察可见行为顺序，不作接触真值或“改夹爪时机必能修复成功”的因果证明。

## 画面与判读规则

两臂每段只执行原动作1..100，保持原环境seed20261022、5个稳定化零动作、相机与原128×128视野；不改变动作或阈值，不新增观察相机，不读物体位置/接触等私有状态，不读取HDF5。

每段保存reset后的帧0和每个动作后的帧1..100，两个uint8 RGB视角逐帧原样存NPZ，并保存相应动作及公开joint/gripper状态。NPZ是无损原证据；MP4是20fps显示预览、3倍nearest放大和文字标签，不恢复额外细节，也不用于数值像素核对。20fps为显示速度，判断以动作步/帧号为准。

首次`action[6]>0.1`为close命令c。**帧c−1是该命令执行前，帧c是执行后**。固定导出c−5/c−1/c/c+1/c+5的有效帧，越界不补齐；100步内没有close则只展示0/100，记窗口内未观测，不能当作全程从未close。

浏览页每对显示A/B双视角视频、共同帧滑杆及事件帧拼图。A/B按固定哈希交换模型顺序，默认不显示模型、seed及原结局；作者已知结果，不能称前瞻盲测。判读CSV模板全部为pending，禁止按动作时刻或关节距离自动填“合爪过早”。

| 判读值 | 需要的可见证据 |
| --- | --- |
| `clearly_before_visible_alignment` | 目标与夹爪均清楚可见，close之前明显尚未形成可见对准关系 |
| `at_or_after_visible_alignment` | 目标与夹爪均清楚可见，close之前已形成可见对准关系；不等于已接触或抓住 |
| `not_assessable` | 遮挡、深度不清、128px细节不足、窗口无close或其他无法可靠判断情况 |

每条非pending记录需要observer、说明和证据帧；作出前两类判断必须包含c−1，目标/夹爪任一不可见时只能记无法判定。原模板不覆盖，复核后另存CSV并核验原命令锚点未变。机器审计只检查记录/证据完整性，不能替代视觉判断或证明因果效应。
